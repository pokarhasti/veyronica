# Veyronica — Distinctive Design Concepts

This document outlines 3 genuinely distinctive, light-themed design concepts crafted specifically for Veyronica's core domain: autonomous agentic replenishment, human-in-the-loop approval gates, ERP purchase order execution, and SHA-256 cryptographic audit trails.

---

## Concept A: "The Editorial Ledger"
*Institutional High-Trust Financial Chronicle*

### Idea & Identity
Treats Veyronica not as a generic dashboard, but as a prestigious, high-trust fiduciary chronicle and cryptographic ledger. Drawing inspiration from financial gazettes, central bank publications, and legal records, it combines warmth, mathematical permanence, and executive gravity.

### Color Palette (Warm Paper & Alabaster)
- **Ground / Background:** `#FDFBF7` (Warm alabaster / rag vellum paper)
- **Card Surfaces:** `#FFFFFF` (Crisp archival white with `#E7E5E4` 1px stone rules)
- **Primary Ink (Text):** `#1C1917` (Stone-black, high contrast, zero glare)
- **Secondary Ink (Labels/Muted):** `#57534E` (Warm charcoal)
- **Accent Primary (Seal):** `#991B1B` (Archival crimson / wax seal vermilion)
- **Accent Secondary (Certified):** `#065F46` (Forest emerald for valid cryptographic chains)
- **Accent Warning (Pending):** `#B45309` (Aged amber bronze)
- **Hairline Rules:** `#E7E5E4` (Crisp 1px borders, no heavy shadows)

### Typography Pairing
- **Display / Headings:** `Playfair Display` or `Cinzel` (authoritative, high-trust editorial serif)
- **Body & Controls:** `Plus Jakarta Sans` (refined geometric editorial sans)
- **Hashes, IDs & Tabular Numbers:** `IBM Plex Mono` (proportional figures, cryptographic ledger alignment)

### Navigation Pattern
- **Top Archival Masthead:** Minimalist newspaper-style header bar with edition metadata ("STORE 214 DISPATCH • BLOCK #8492"), live cryptographic status, and an elegant horizontal rule-separated navigation strip.

### Signature Layout
- **Ledger Sheet Grid:** Single-pixel hairline dividers (`border-stone-200`) separating columns without heavy card containers. Generous whitespace, indented metadata blocks, and legal-style marginal notes.

### Signature Components
- **Wax-Seal Status Badges:** Monospace tracked stamps with double-border rules (e.g. `[ APPROVED • RM-001 ]`).
- **Dotted Tabular Leaders:** Line items with dot matrices (`...`) connecting SKU names to order values.
- **Cryptographic Hash Chain:** Rendered as an embossed certificate strip with green verification ribbon and SHA-256 hash segments formatted in 4-character blocks.

### Detailed Page: HomePage (The Daily Procurement Chronicle)
- Top masthead displays store volume index and temporal block ticker.
- Main column features "Today's Stockout Intervention" in broadsheet format with highlighted supplier MOQ constraints.
- The What-If simulation is presented as an interactive "Balance Sheet Simulator" with tactile horizontal rule adjustments.

## Concept B: "Command Dock & Precision Bento"
*Tactile Autonomous Aerospace Infrastructure*

### Idea & Identity
Inspired by aerospace mission control, modern dev tooling (Linear, Railway, Arc), and tactical instrumentation. Focuses on speed, tactile precision, modular bento cards, and a distraction-free canvas where the navigation floats gracefully.

### Color Palette (Porcelain & Precision Cyan)
- **Ground / Background:** `#F8FAFC` (Cool porcelain mist)
- **Bento Surfaces:** `#FFFFFF` (Pure white tiles with subtle `#E2E8F0` micro-borders)
- **Primary Text:** `#0F172A` (Obsidian slate)
- **Secondary Text:** `#64748B` (Cool graphite)
- **Accent Primary (Telemetry):** `#0D9488` (Precision Teal / Cyber Cyan)
- **Accent Electric:** `#4F46E5` (Iris Cobalt for interactive buttons)
- **Status Indicators:**
  - Active / Healthy: `#16A34A` (Radar green)
  - Awaiting Gate: `#F59E0B` (Amber warning beacon)
  - Breached: `#EF4444` (Emergency red)
- **Micro Shadows:** `0 1px 3px rgba(15,23,42,0.04), 0 4px 12px rgba(15,23,42,0.03)`

### Typography Pairing
- **Display / Headings:** `Outfit` (punchy, geometric, technical grotesque)
- **Body & Controls:** `Satoshi` (ultra-clean, balanced contemporary sans)
- **Hashes, IDs & Code:** `Geist Mono` (compact, razor-sharp technical mono)

### Navigation Pattern
- **Floating Command Dock:** Floating bottom-center or top pill-shaped dock with tactile icon badges, active glowing dot pips, and a built-in `Cmd+K` quick action search palette.

### Signature Layout
- **Dynamic Bento Grid:** Asymmetric tiles where each card has a distinct density. Larger telemetry cards for inventory burn-down curves, compact capsule tiles for role permissions and adapter pings.

### Signature Components
- **Pill Controls:** High-radius pill buttons (`rounded-full`) with crisp inset borders and tactile pressed states.
- **Pulse Radar Stepper:** Live pipeline stepper featuring pulsating radar pips and animated connectors that glow when an activity is processing.
- **Tactile Toggle Switches:** Hardware-inspired toggles and sliders for What-If scenarios.

### Detailed Page: HomePage & Run Detail
- Hero section is an asymmetric Bento Board: Top-left tile hosts the instant Replenishment Launchpad; top-right tile displays live Adapter Telemetry (Temporal, ERP, Supplier, Inventory); bottom tile hosts the What-If Sandbox with interactive dials.
- Run Detail page presents each activity as a modular telemetry block with expandable JSON payload trays and real-time execution timers.

## Concept C: "Kinetic Flow Ribbon"
*Agent Cognitive Stream & Canvas*

### Idea & Identity
Puts the 5-stage agent reasoning pipeline (Signal -> Constraint -> Draft -> Route -> Execute) front and center. Built for users who want to see *how* the agent thinks. Uses fluid stream ribbons, node connections, and master-detail views to visualize the reasoning process.

### Color Palette (Nordic Ice & Stream Sapphire)
- **Ground / Background:** `#F1F5F9` (Nordic ice / clean chalk)
- **Flow Canvas:** `#FFFFFF` (White panels with 2px stage-colored status left borders)
- **Stream Accent:** `#0284C7` (Stream sapphire / deep sky)
- **Cognitive Loop Purple:** `#7C3AED` (Violet accent for AI draft reasoning)
- **Primary Text:** `#1E293B` (Deep navy slate)
- **Secondary Text:** `#64748B` (Muted steel)
- **Stage Colors:**
  - Signals: `#6366F1` (Indigo)
  - Constraints: `#F59E0B` (Amber)
  - Drafts: `#8B5CF6` (Purple)
  - Approval: `#EC4899` (Rose-pink gate)
  - Execution: `#10B981` (Emerald completion)

### Typography Pairing
- **Display / Headings:** `Space Grotesk` (rhythmic, expressive tech grotesque)
- **Body & Controls:** `DM Sans` (approachable, humanistic, high readability)
- **Hashes & Technical IDs:** `Space Mono` (distinctive mathematical monospace)

### Navigation Pattern
- **Persistent Horizontal Flow Ribbon:** A top pipeline ribbon that shows the current workflow state globally, doubles as a progress stepper and page navigation link.

### Signature Layout
- **Master-Detail Flow Split:** Left column streams the agent cognitive thoughts and inventory signals chronologically; right column displays the live resulting PO preview and cryptographic audit verification side-by-side.

### Signature Components
- **Stage Node Connectors:** Curved visual connectors between pipeline steps indicating data flow.
- **Dual-Pane Action Cards:** Left half shows the constraint evaluation and hallucination guard check; right half displays the executable PO action.
- **Scrubber Timeline:** An interactive timeline slider allowing the user to step back and forward through each activity in the workflow.

### Detailed Page: RunDetailPage
- Prominent interactive flow ribbon across the top displaying the exact activity path.
- Split-screen workspace: Left side displays LangGraph cognitive node outputs (inventory velocity graph, MOQ bounds, LLM rationale); right side displays generated PO document with dual-gate approval triggers.
